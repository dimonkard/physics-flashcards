# Физика: флеш-карточки ОГЭ и ЕГЭ

Статический адаптивный сайт без серверной части. Можно разместить на GitHub Pages.

## Размещение

1. Создайте публичный репозиторий на GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория (`index.html`, `styles.css`, `data.js`, `extra.js`, `app.js`).
3. В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите `main` и `/ (root)`, нажмите **Save**.
5. Сайт появится по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Использование

Выберите ОГЭ или ЕГЭ, отметьте фильтр «Все», «Знаю», «Не знаю» или «Новые». Режим заучивания переворачивает карточки, режим проверки предлагает четыре ответа. Ошибочные ответы и карточки с отметкой «Не знаю» можно повторить отдельно. Прогресс хранится в `localStorage` телефона, без регистрации и синхронизации между устройствами.

## Банк формул

`data.js` — первоначальные формулы; `extra.js` — дополнительные формулы. Каждая карточка содержит название, LaTeX-формулу, уровень экзамена и необязательную подсказку. Данные составлены по формульным элементам школьного курса, ориентированы на кодификаторы ФИПИ 2026. **Кодификатор — перечень проверяемых элементов содержания, а не готовый исчерпывающий каталог карточек**; некоторые элементы проверяются как понятия, рисунки или графики. Для использования как строго официального исчерпывающего справочника необходима поэлементная методическая сверка, поэтому не следует считать данный авторский банк официальным документом ФИПИ.

Официальные документы: https://fipi.ru/ege/demoversii-specifikacii-kodifikatory и https://fipi.ru/oge/demoversii-specifikacii-kodifikatory

Для отображения формул используется MathJax с CDN, поэтому при первом открытии требуется интернет.
